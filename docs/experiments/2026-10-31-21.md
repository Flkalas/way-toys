## 준비·검사

소스 전송과 빌드는 다음 순서로 수행했다. rsync는 삭제 옵션 없이 동작한다.

```powershell
wsl.exe -d Ubuntu-24.04 -e rsync -rt --exclude=.git/ --exclude=target/ --exclude=.artifacts/ -e /mnt/c/Windows/System32/OpenSSH/ssh.exe /mnt/d/Github/utils/way-toys/ debian@192.168.50.125:/home/debian/projects/way-toys/
ssh debian@192.168.50.125 '. ~/.cargo/env; cd ~/projects/way-toys; cargo fetch'
ssh debian@192.168.50.125 '. ~/.cargo/env; cd ~/projects/way-toys; cargo check --workspace'
ssh debian@192.168.50.125 '. ~/.cargo/env; cd ~/projects/way-toys; cargo fmt --all; cargo test --workspace; cargo build --workspace'
```

의존성 추가 후 게스트의 Cargo.lock과 포맷된 수정 소스를 Windows로 가져왔다. 이후 검사는 `--locked`를 사용했다. 실행은 [scripts/zones-settings-vm.ps1](../../scripts/zones-settings-vm.ps1)의 Start/Input/Capture/Check를 사용했고, 입력은 [vm-input.py](../../scripts/vm-input.py)로 VM 700의 QMP에 보냈다. 로컬 키보드/다른 VM에는 입력하지 않았다.

기존 표시 서비스 `waytoys-canvas-preview-dev`만 종료했다. `grid-editor-16/config/outputs`의 두 파일을 새 `settings-21/config/outputs`로 복사해 레이아웃 보존 대조군으로 사용했다. 원본 디렉터리에는 쓰지 않았다.

```powershell
.\scripts\zones-settings-vm.ps1 -Action Start
.\scripts\zones-settings-vm.ps1 -Action Input -Events docs\experiments\artifacts\2026-10-31-21\input-general-open.json
.\scripts\zones-settings-vm.ps1 -Action Capture -OutputDirectory docs\experiments\artifacts\2026-10-31-21\initial
.\scripts\zones-settings-vm.ps1 -Action Check
```

위 Start의 실제 기본값은 unit `waytoys-settings-21`, config `/home/debian/waytoys-test-results/settings-21/config`, Wayland `wayland-0`, `WINIT_UNIX_BACKEND=wayland`, `ICED_BACKEND=tiny-skia`다. Input의 정규화 기준은 1962×627이었다. 캡처는 VM 내부 Spectacle→PNG 클립보드→SCP→SHA-256 검증이며 Windows 클립보드는 건드리지 않았다. 캡처별 manifest/출력 JSON/시각/로그도 하위 디렉터리에 있다.

## 실제 입력 순서와 관찰

각 입력 파일은 `-Action Input -Events <파일>`로 실행했다. 창 위치·KWin 배치가 달라지면 좌표를 다시 확인해야 하며, 이 JSON을 다른 화면 배치에 그대로 적용해서는 안 된다.

1. `input-general-open.json`, `input-general-appearance.json`: 모든 모니터 체크, 겹침 선택 Largest. [초기 창](artifacts/2026-10-31-21/initial/clipboard.png), [선택 메뉴](artifacts/2026-10-31-21/general-menu/clipboard.png).
2. `input-partial.json`: 번호 끄기, 불투명도 72, HEX `#12`. [미완성 입력](artifacts/2026-10-31-21/partial-input/clipboard.png)과 [저장 JSON](artifacts/2026-10-31-21/preferences-partial.json)에서 숫자/체크는 저장되고 색상은 기존 `#008CFF`를 유지했다.
3. `input-color-excluded.json`: 완성 HEX `#ff4400`을 VM 클립보드에서 Ctrl+V로 입력하고 제외 앱 범주로 이동했다. 같은 입력이 한 차례 중복 실행되어 제외 앱에 색 문자열이 들어간 뒤, 다음 단계에서 올바른 앱 ID로 교체했다.
4. `input-excluded.json`: `org.kde.konsole\norg.example.TestApp`을 붙여넣었다. [결과](artifacts/2026-10-31-21/excluded-after/clipboard.png), [저장·메모리](artifacts/2026-10-31-21/first-session-state.log). 실제 값은 줄바꿈 두 줄이며 대소문자를 유지했다.
5. `input-close-first.json`: 닫기 후 MainPID=0을 확인하고 `-Action Start -Unit waytoys-settings-21-reopen`으로 같은 config를 재실행했다. [재실행 화면](artifacts/2026-10-31-21/reopened/clipboard.png)에 값이 복구됐다.
6. `input-open-editor.json`: Virtual-1 Grid 에디터 실행. 같은 config로 CLI를 추가 실행하면 종료값 1과 잠금 오류가 났다([근거](artifacts/2026-10-31-21/duplicate-editor.log)).
7. `input-live-appearance.json`: 번호를 켜고 비활성색을 `#35bb88`로 입력했다. [동시 반영 화면](artifacts/2026-10-31-21/editor-after/clipboard.png)에서 2구역 구조 및 `541×448`, `259×448` 치수를 유지했다.
8. `input-move-first-monitor.json`, `input-close-editor.json`: 첫 모니터로 이동하고 에디터 Cancel. 경계 이동 첫 클릭은 Cancel에 닿지 않아 다시 클릭했으며, 최종 종료를 확인했다.
9. `input-resize-min.json`, `input-resize-corner.json`, `input-resize-keyboard.json`: 마우스 모서리/Alt+F8 시도는 실제 크기를 바꾸지 못했다. 이를 성공으로 판정하지 않았다. `qdbus6 org.kde.KWin /KWin queryWindowInfo`와 `input-query-window.json`으로 해당 창 UUID/geometry를 확인했다.
10. 실제 등록된 `Window Resize` 동작을 아래처럼 시작하고 `input-resize-kwin.json`의 포인터 이동/Enter로 크기를 줄였다. [geometry](artifacts/2026-10-31-21/minimum-geometry.log)는 외곽 562×329(클라이언트 560×300)였다. [최소 크기](artifacts/2026-10-31-21/minimum-kwin/clipboard.png), `input-scroll-min.json`의 [하단 미리보기 접근](artifacts/2026-10-31-21/minimum-scroll/clipboard.png)을 확인했다.
11. `input-window-category.json`, `input-window-name.json`: 창 동작의 미적용 안내와 체크 입력, 이름 표시 범주를 확인했다. `input-close-min.json`으로 종료했다.

```powershell
ssh debian@192.168.50.125 'XDG_RUNTIME_DIR=/run/user/1000 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus qdbus6 org.kde.kglobalaccel /component/kwin invokeShortcut "Window Resize"'
```

이는 기존 KWin 동작 호출을 통한 시험이며 제품의 전역 단축키 등록이 아니다. 단축키 설정 파일은 변경하지 않았다.

클립보드 준비는 UTF-8 값을 Base64로 인코딩해 다음 형식으로 보냈다. 최초에는 출력 리다이렉션을 생략해 wl-copy의 소유 프로세스가 SSH 채널을 유지했다. 같은 값을 출력 리다이렉션으로 다시 설정해 대기를 해제했고, 도구의 Clipboard 동작에도 이 수정을 반영했다.

```powershell
$encoded = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('#ff4400'))
ssh debian@192.168.50.125 "printf %s '$encoded' | base64 -d | XDG_RUNTIME_DIR=/run/user/1000 WAYLAND_DISPLAY=wayland-0 wl-copy >/dev/null 2>&1"
```

## 실패·수정·보존 범위

- 초기 로컬 명령 실행은 샌드박스 초기화 오류로 실패했다. 권한 모드 변경 후 정상 실행했다. 제품 원인으로 분류하지 않는다.
- 최초 Clippy는 신규 테스트의 `field_reassign_with_default` 한 곳을 지적했다. 구조체 초기화로 고친 뒤 통과했다. 실패 로그는 [check-console.log](artifacts/2026-10-31-21/check-console.log)에 남겼다.
- VM의 기존 창 관리자는 새로 설치한 CJK 글꼴로 제목을 즉시 표시하지 못했다. 창 관리자 제목을 `Zones`, 본문 제목을 한국어로 정리했다. 본문은 Noto로 정상 표시됐다.
- 미리보기의 겹친 번호는 각 구역 왼쪽 위로 옮겼다. 이름 라벨은 에디터 도구 모음/하단 상태를 피하도록 수정했다. 작은 창의 범주 메뉴도 스크롤하도록 했다.
- 에디터까지 Noto CJK를 fontdue로 로드한 중간 빌드에서 RSS 약 329 MiB와 초기 지연을 관찰했다. 요청된 Noto 사용은 설정 창에 적용하고, 기존 에디터 글꼴 경로는 원래 sans-serif로 유지했다. 최종 값은 22회차에서 다시 측정했다.
- 캡처를 겹쳐 시작한 한 번은 기존 Spectacle 창이 있다는 보호 오류로 중단됐다. 소유한 캡처 서비스 종료 후 다음 캡처는 정상 진행했다.

레이아웃 SHA-256은 시험 전후 동일했다: Virtual-1 `fd2469c01e3719989c1835d7020d649497c99db3bfe0ce9e364c5c128cf3af1d`, Virtual-2 `317cce4fb914f530fda6378767dc2fc0af11ada820cd6c9f9066e15d2626cde6`. [종료·보존 기록](artifacts/2026-10-31-21/closed-final.log).

이 회차는 구현 도중의 비교 시험이다. 중간 바이너리별 전체 소스 스냅샷은 남기지 않았으며 초기 캡처를 최종 코드 검증으로 대신하지 않는다. 최종 코드/해시/추가 검사 및 종료 후 전달 상태는 [22회차](2026-10-31-22.md)에 기록한다. 실제 KWin 창 배치, 단축키 등록, 다른 compositor/OS, 장시간 부하와 저장 장치 고장은 시험하지 않았다.
