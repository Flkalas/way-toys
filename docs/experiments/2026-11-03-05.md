Debian 13.7, Linux 6.12.113+deb13-amd64, Rust/Cargo 1.99.1, KWin 6.3.6, Qt 6.8.2, Python 3.13.5, xclip 0.13, xdotool 3.20160805.1이다. Xvfb 패키지는 `2:21.1.16-1.3+deb13u4`다. 공통 의존성·준비·격리·정리는 [01회차](2026-11-03-01.md#공통-준비와-격리)를 따른다. 이 회차의 명령과 인수는 아래에 따로 적었다.

```sh

cargo build --workspace > docs/experiments/artifacts/2026-11-03-01/build-fifth.log 2>&1

```

## 한계·후속 기록

마지막 runtime 스냅샷은 캡처 종료 직후 `ready=false`, `error=null`이었다. 이 회차에서는 Zones 재연결 완료를 기다리지 않았으므로 복구 완료의 근거로 삼지 않는다. 이후 확장 시험에서 ready=true를 기다렸다. 기록 창 선택·재복사·재시작과 두 화면 시험은 아직 수행하지 않았다.
