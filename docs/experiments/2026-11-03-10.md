# 2026-11-03-10 X11 호환 최종 자동 검사와 통합 시험

## 목적·환경·코드

2026-11-03 KST, `/home/mark/Sources/way-toys`에서 X11 호환 변경의 최종 상태를 검사했다. 기준 HEAD는 `47bd992`이며 X11 구현·문서의 미커밋 변경을 포함한다. 실행 당시 [소스 SHA-256](artifacts/2026-11-03-10/integration/source-manifest.json), [환경·실행 명령](artifacts/2026-11-03-10/integration/environment.json), [당시 시험 스크립트](artifacts/2026-11-03-10/integration/test-x11.py)를 보존한다.

Debian 13.7, Linux 6.12.113+deb13-amd64, KWin 6.3.6, Qt 6.8.2, Rust/Cargo 1.99.1, Python 3.13.5, xclip 0.13, xdotool 3.20160805.1, Xvfb `2:21.1.16-1.3+deb13u4`를 사용했다. 디버그 빌드, 소프트웨어 OpenGL 합성이다. Noto CJK/fontconfig는 설치되어 있으며 정확한 글꼴 패키지 버전은 미확인이다. 도구 버전은 [01회차 로그](artifacts/2026-11-03-01/tool-versions.log)에 있다.

XRandR 1.5·XInput 2.1·XFixes를 제공하는 별도 Xvfb `1280x720x24`에 KWin X11을 실행했다. 별도 D-Bus와 임시 XDG 경로를 사용했다. 실제 사용자 창·클립보드·단축키는 조작하지 않았다. 공통 준비·Qt fixture 빌드·인증·프로세스 정리는 [01회차](2026-11-03-01.md#공통-준비와-격리)를 따른다. 이번에는 `--split-monitors`를 사용해 마지막에 640×720 합성 모니터 두 개를 구성했다.

## 실제 명령과 순서

09회차 Clippy 오류를 수정하여 테스트 모듈을 파일 끝으로 옮겼다. 다음 명령을 저장소 루트에서 `&&`로 순서대로 실행했다.

```sh
mkdir -p docs/experiments/artifacts/2026-11-03-10
cargo fmt --all
cargo test --workspace --locked > docs/experiments/artifacts/2026-11-03-10/test.log 2>&1
cargo fmt --all -- --check > docs/experiments/artifacts/2026-11-03-10/fmt.log 2>&1
cargo clippy --workspace --all-targets --locked -- -D warnings > docs/experiments/artifacts/2026-11-03-10/clippy.log 2>&1
cargo build --workspace --locked > docs/experiments/artifacts/2026-11-03-10/build.log 2>&1
python3 scripts/test-x11.py --xvfb /home/mark/Sources/way-toys/.artifacts/x11-tools/usr/bin/Xvfb --split-monitors --output docs/experiments/artifacts/2026-11-03-10/integration > docs/experiments/artifacts/2026-11-03-10/integration.log 2>&1
```

입력 문자열·이미지는 Qt fixture의 고정 공개 데이터만 사용한다. 시험 내부의 실행 순서와 실제 인수는 [commands.jsonl](artifacts/2026-11-03-10/integration/commands.jsonl)에 기록했다. 인증 쿠키는 가렸다. 스크립트에서 `XDG_SESSION_TYPE=x11`, `QT_QPA_PLATFORM=xcb`, `LIBGL_ALWAYS_SOFTWARE=1`, `KWIN_COMPOSE=O2`를 설정하고 `WAYLAND_DISPLAY`를 제거했다. DISPLAY·XAUTHORITY는 시험 서버의 임시 값이다. systemd-run 래퍼는 클립보드 scope를 만들 때만 원래 사용자 매니저에 연결한다.

## 한계

두 화면은 XRandR 합성 모니터로, 실제 물리 모니터·회전·확대 변환 시험이 아니다. 잠금 상태 서비스는 시험용이며 실제 화면 잠금은 이 회차에서 수행하지 않았다. 단축키 설치·재로그인, 비KWin 창 관리자·다른 KWin 버전, 장시간·대형 이미지 부하, release 성능과 메모리는 미검증이다. Wayland 실제 세션 입력 시험도 재실행하지 않았으며 기존 코드 보존·빌드·단위 테스트 확인과 구분한다. X11의 드래그 창 투명화는 적용하지 않으며 설정 UI와 [사용 안내](../x11.ko.md)에 명시했다.
