## 실제 실행 순서

Shift·Ctrl·Esc와 왼쪽 버튼 전환만 보관하는 XInput 2.1 경로를 추가하고 취소 시 KWin이 바꾼 창 프레임·tile 연결을 복구하도록 수정했다.

```sh
cargo fmt --all
cargo build --workspace --locked > docs/experiments/artifacts/2026-11-03-01/build-eighth.log 2>&1
python3 scripts/test-x11.py --xvfb /home/mark/Sources/way-toys/.artifacts/x11-tools/usr/bin/Xvfb --split-monitors --output docs/experiments/artifacts/2026-11-03-08 > docs/experiments/artifacts/2026-11-03-01/integration-eighth.log 2>&1
```
