## 메모리·CPU·정리

[measure-zones-processes.py](../../scripts/measure-zones-processes.py)는 명시한 systemd user unit의 MainPID에 대해 `/proc/status`, `smaps_rollup`, CPU tick을 10초 간격으로 읽는다. 메모리 값은 해당 프로세스 값이며 VM 전체 사용량이나 캐시 포함 할당량이 아니다.

```powershell
ssh debian@192.168.50.125 'python3 /home/debian/projects/way-toys/scripts/measure-zones-processes.py waytoys-settings-22-final waytoys-preview-22 --seconds 10'
ssh debian@192.168.50.125 'python3 /home/debian/projects/way-toys/scripts/measure-zones-processes.py waytoys-zones-settings-dev --seconds 10'
```

| 상태 | RSS / HWM (KiB) | PSS (KiB) | thread | 10초 CPU 시간 증가 |
|---|---:|---:|---:|---:|
| 설정 창, 최종 제목 컨테이너 정리 전 | 103,512 / 103,512 | 98,699 | 5 | 0.41초 |
| 전체 화면 Canvas 표시 | 28,432 / 28,432 | 24,995 | 1 | 0.00초 |
| 전달용 최종 설정 창, 입력 없음 | 103,540 / 103,540 | 98,647 | 5 | 0.00초 |

근거: [이전 비교 샘플](artifacts/2026-10-31-22/memory-before-title-fix.json), [최종 샘플](artifacts/2026-10-31-22/memory-final.json). 최종 설정 RSS는 약 101.1 MiB, PSS는 약 96.3 MiB다. 0.00초는 계측 해상도 안에서 증가가 없었다는 뜻이다. 이전 0.41초의 정확한 원인은 분리 측정하지 않았다. 입력 포커스/커서 상태가 달라 두 샘플을 최적화 효과로 단정하지 않는다. 장시간 누수, release 빌드, 실제 GPU/다른 compositor 성능은 이 측정으로 판단하지 않는다.

## 실제 캡처 전달과 한계

최종 캡처는 `-Action Capture -OutputDirectory docs\experiments\artifacts\2026-10-31-22\delivery`로 가져왔다. [manifest](artifacts/2026-10-31-22/delivery/manifest.json)의 PNG SHA-256은 `17fe56b81d483e7e89a2b9c3255117221d4680fa8bb8a76406a06de83f20a225`다. 설정 창 본문 제목, 한국어 입력 폼, 번호/색상 Canvas, 저장 완료 상태가 보인다.

Orca에서 전체 화면 반영 캡처와 전달 창 캡처를 각각 `orca tab create --url <로컬 PNG URL> --json`으로 열고 page별 snapshot/eval을 수행했다. 두 이미지 모두 `complete=true`, `naturalWidth=3922`, `naturalHeight=1252`였다. [이 작업의 두 탭 기록](artifacts/2026-10-31-22/browser-tabs.json)만 보존했다. 기존 사용자 탭은 닫거나 바꾸지 않았다.

KWin 창 배치, 실행 화면 자동 정책, 제외 앱 적용, 전역 단축키 등록은 구현 범위에 포함하지 않았다. 제품 UI에 미적용 상태를 명시했다. 파일 시스템 전원 손실/fsync 실패, SIGKILL 종료, 모니터 hotplug, 장시간 부하, 다른 Linux 배포판/Windows 네이티브 실행은 미검증이다. 실행 방법과 지원 범위는 [공통 설정 안내](../zones-settings.ko.md)를 따른다.
