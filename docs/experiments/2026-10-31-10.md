# 2026-10-31-10 VM 내부 전체 화면 오버레이와 클립보드 PNG 수집

## 환경과 변경

2026-10-31 03:37 KST, VM 700 Debian 13, 커널 6.12.113+deb13-amd64, Plasma/KWin 6.3.6, Spectacle 6.3.5, wl-clipboard 2.2.1. Git `c02799b` 위 미커밋 변경이다. Rust 1.99.1 빌드·테스트 4개·Clippy가 통과했다. 각 출력 전체에 색과 논리 2픽셀 테두리를 그리고, 재사용 SHM 슬롯의 여분 영역을 건드리지 않는 코드다.

Virtual-1 848×480 100%, Virtual-2 1280×720 115%, 논리 시작 X는 각각 0과 848이다. 실제 로그인된 Wayland 세션에서 실행했다. 준비 패키지는 `sudo apt-get install -y --no-install-recommends kde-spectacle wl-clipboard`로 설치했다.

## 실제 명령

Windows PowerShell, `D:\Github\utils`에서 다음 순서로 실행했다. Qt/KWin 캡처이므로 QEMU 프레임버퍼를 이미지 원본으로 사용하지 않았다.

```powershell
ssh debian@192.168.50.125 'sudo loginctl unlock-session 1; systemd-run --user --unit=waytoys-native-overlay --collect /home/debian/projects/way-toys/target/debug/waytoys-overlay --display; systemd-run --user --unit=waytoys-spectacle-editor --collect /usr/bin/spectacle --fullscreen --gui'
# Spectacle이 시작되고 캡처 창이 활성화된 뒤 실행했다.
ssh INOPS-PVE 'printf "sendkey ctrl-c\nquit\n" | qm monitor 700'
ssh debian@192.168.50.125 'mkdir -p /home/debian/waytoys-test-results/2026-10-31-10; XDG_RUNTIME_DIR=/run/user/1000 WAYLAND_DISPLAY=wayland-0 wl-paste --list-types > /home/debian/waytoys-test-results/2026-10-31-10/clipboard-types.log; XDG_RUNTIME_DIR=/run/user/1000 WAYLAND_DISPLAY=wayland-0 wl-paste --type image/png > /home/debian/waytoys-test-results/2026-10-31-10/clipboard.png'
```

SCP로 [원본 PNG](artifacts/2026-10-31-10/vm700-native-clipboard.png)를 Windows에 가져와 파일 탭으로 열었다. 클립보드에는 `image/png` 등 이미지 MIME 타입들이 있었고 PNG는 3922×1252였다. VM과 로컬 SHA-256은 `5ece0a373cdd7a0db53b344a20ef932beb9204c4ad1f5ec82771237838c28c7e`로 같았다. 두 출력이 수평으로 맞붙고 각 테두리가 각 화면 끝에 일치함을 직접 확인했다. 높이가 다른 화면 아래에는 바탕화면 영역이 없는 검은 부분이 있다.

## 범위와 정리

이 회차는 표시와 PNG 수집을 확인한 것이다. 드래그 정확성은 검증하지 않았다. Spectacle과 시험 오버레이는 종료했다. 종료 전 저장된 PNG를 wl-copy로 다시 제공했으며 다음 회차의 자동 도구에서는 이 유지 과정을 제거했다.

이 회차에서 Windows 클립보드에도 이미지를 복사했으나, 이후 사용자 지시에 따라 개발 도구는 Windows 클립보드를 읽거나 변경하지 않는다. 당시 수동 캡처 단계와 이후 자동 도구는 구분한다. 현재 재사용 경로는 [캡처 도구](../vm-capture.ko.md)다.
