# 2026-10-30-01 로컬 X11 재시험

2026-10-30 `DISPLAY=:0`, KDE X11, `loginctl`의 `Remote=no`인 로컬 세션에서 같은 격리 중첩 KWin과 `xdotool` 합성 드래그를 다시 실행했다. 첫 출력 800×600·100%, 둘째 출력 600×400에서 (150,100)→(450,300)을 드래그했다. 둘째 출력이 100%면 `output=1 x=150 y=100 width=300 height=200`이었고, 150%면 `output=0 x=633.33203125 y=66.6640625 width=165.66796875 height=133.3359375`로 잘못 선택되었다. 두 창은 서로 떨어져 있었으며, 혼합 배율 시각 캡처는 [XRDP 실험 이미지](2026-10-29-02.md)와 각각 바이트 단위로 같았다.

이 결과는 앞선 현상이 XRDP 세션에서만 나타나는 것은 아님을 보여준다. 다만 양쪽 모두 X11 위의 중첩 KWin과 합성 입력이므로 물리 Wayland 로그인이나 실제 마우스에서도 발생한다는 뜻은 아니며, 문제가 KWin, 입력 주입 또는 클라이언트 중 어디에서 발생하는지 아직 구분하지 못했다.

공통 재현 절차: [Wayland 오버레이 기술 검증](../overlay-poc.ko.md).
