# 2026-10-31-25 설정 창의 예시 미리보기 제거

## 변경과 환경

설정 창 오른쪽(좁은 창에서는 위쪽)에 있던 Grid/Canvas 예시 미리보기를 제거했다. 다섯 범주의 설정은 본문 너비를 사용하는 한 열로 스크롤한다. 미리보기 전용 모듈·메시지·상태와 Iced `canvas` 기능을 제거했다. 기존 전체 화면 오버레이 편집기와 실제 드래그 오버레이 코드는 변경하지 않았다.

2026-10-31 KST, Windows `D:\Github\utils\way-toys`, Debian 13.7 / KWin 6.3.6 개발 VM 700에서 수행했다. 기준 HEAD와 변경 파일 해시는 `source-manifest.json`에 기록했으며, 미커밋 변경이 포함된다. 환경·격리 경로는 [24회차](2026-10-31-24.md)와 같다. 모니터는 Virtual-1 848×480·100%, Virtual-2 1280×720·115%다. 사용 설정은 `/home/debian/waytoys-test-results/settings-23/{app,zones}`이며 사용자 기본 설정 경로를 사용하지 않았다.

## 빌드

Windows 저장소 루트에서 소스를 전송하고 게스트에서 검사했다.

```powershell
wsl.exe -d Ubuntu-24.04 -e rsync -rt --exclude=.git/ --exclude=target/ --exclude=.artifacts/ --exclude=docs/experiments/artifacts/ -e /mnt/c/Windows/System32/OpenSSH/ssh.exe /mnt/d/Github/utils/way-toys/ debian@192.168.50.125:/home/debian/projects/way-toys/
```

```bash
cd ~/projects/way-toys
. ~/.cargo/env
rm -f crates/waytoys-zones-settings/src/preview.rs
cargo fmt --all
cargo test --workspace --locked
# 위 명령은 canvas 기능 제거에 따른 lockfile 갱신 필요로 중단됐다.
cargo test --workspace --offline
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo build --workspace --locked
cargo fmt --all -- --check
```

`build.log`에 최초 lockfile 오류, `build-final.log`에 **90개 테스트 통과**, Clippy·빌드·fmt 성공을 보존했다. `Cargo.lock.before`와 최종 lockfile을 비교했으며 불필요해진 패키지만 제거되고 새 패키지나 버전 변경은 없었다. 게스트에서 포맷한 `lib.rs`, `view.rs`와 갱신된 `Cargo.lock`을 로컬에 다시 가져왔다. 정적 검색에서 설정 crate의 `Preview`, `canvas_mode`, `canvas` 기능 참조가 남지 않은 것도 확인했다. 기존 편집기의 별도 preview 모듈은 제거 대상이 아니다.

## VM 확인

아래 파일은 `docs/experiments/artifacts/2026-10-31-25` 기준이다. 새 테스트는 추가하지 않고 기존 검사와 실제 화면을 확인했다.

1. 기존 설정 창에 `qdbus6 org.waytoys.Settings1 /Settings org.waytoys.Settings1.Close refresh`를 호출했다. 직후 새 창을 시작한 첫 시도에서는 창이 남지 않았다(`restart.log`). `normal/screen.png`는 이 상태의 바탕화면이며 GUI 검증 근거로 사용하지 않는다.
2. D-Bus `NameHasOwner`가 false임을 확인하고 `restart-final.sh`의 명령으로 새 설정 창을 시작했다. 같은 개발 경로, `--page zones`, `ICED_BACKEND=tiny-skia`, transient unit `waytoys-settings-25`를 사용했다. 실행기 PID 58276은 재시작하지 않고 유지됐다.
3. `kwin-window-probe.py --caption Waytoys --app waytoys-settings --place 43 15 762 409`로 기본 크기와 위치를 준비했다. `normal-final/screen.png`에서 미리보기가 없고 설정·모니터 선택·에디터 열기·저장 상태가 표시됨을 확인했다.
4. 같은 도구로 frame 562×329를 준비했다. `scroll-bottom-input.json`의 실제 QMP 휠 입력으로 마지막 제외 앱 입력까지 내려갔다. `minimum-geometry.json`, `minimum/screen.png`에서 최소 크기·스크롤·고정 닫기 버튼을 확인했다. 창 크기와 위치는 이 회차에서는 준비 스크립트로 지정했으며 실제 테두리 드래그로 기록하지 않는다.
5. `open-editor-input.json`의 실제 클릭으로 ‘에디터 열기’를 눌렀다. `editor-process.log`의 프로세스 인수는 기존 `waytoys-zones-editor --config-dir .../settings-23/zones --output Virtual-1`이다. `editor/screen.png`는 기존 Grid 편집기·치수·Save/Cancel 툴바다. `cancel-editor-input.json`으로 Cancel을 눌렀고 편집기 프로세스가 종료됐다.
6. frame을 `[910,10,990,600]`으로 지정하여 115% 화면에 놓고 `scroll-top-input.json`의 실제 휠 입력으로 처음까지 올렸다. `delivery/screen.png`에서 한글과 본문 전체 너비의 설정을 확인했다. 실제 frame 너비는 배율 반올림으로 990.43이다.

입력과 캡처는 각각 아래 도구로 실행했다. 각 입력 파일은 위 순서에 따라 사용했다.

```powershell
.\scripts\zones-settings-vm.ps1 -Action Input -Events docs\experiments\artifacts\2026-10-31-25\open-editor-input.json -OutputDirectory docs\experiments\artifacts\2026-10-31-25
.\scripts\capture-wayland-file.ps1 -OutputDirectory docs\experiments\artifacts\2026-10-31-25\editor
```
