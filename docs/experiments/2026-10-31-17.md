# 2026-10-31-17 Canvas 겹침 예제의 실제 Wayland 표시

## 목적·환경

2026-10-31 KST, 사용자가 요청한 Canvas 겹침 예제를 VM에 표시하고 캡처 탭으로 전달했다. develop 기준 HEAD `c02799b7bfb7f86a04fa85da0d5ad142f1000b9b` 위 미커밋 작업이며 기존 변경을 보존했다. 환경은 [16회차](2026-10-31-16.md)의 VM 700, Debian 13.7, KWin 6.3.6 Wayland, Rust/Cargo 1.99.1이다. Virtual-1은 848×480·100%, Virtual-2는 1280×720·115%다.

## 구현과 실제 실행

`waytoys-zones-editor --preview FILE [--layout-index N]`을 추가했다. 기존 `calculate_custom`이 Canvas/Grid를 surface 로컬 좌표로 계산하고 기존 렌더러가 표시한다. 편집 controller와 저장 경로는 사용하지 않으며 모니터 전환과 닫기만 제공한다.

[입력 예제](../../crates/waytoys-zones-editor/examples/canvas-overlap.json)는 기준 1280×720에서 1번 `(80,140,620,450)`, 2번 `(510,260,640,380)`, 3번 `(800,120,360,200)`, 4번 `(130,185,200,140)`이다. 1·2와 2·3은 부분적으로 겹치고 4는 1 안에 포함된다. 최초 3번 높이는 230이었으나 크기 라벨과 2번 테두리가 겹쳐 보이므로 예제 높이를 200으로 조정했다. 캡처 이미지를 편집한 것이 아니라 입력 레이아웃을 바꾼 뒤 다시 실행했다.

Windows PowerShell 7의 `D:\Github\utils\way-toys`에서 기존 rsync 방식으로 전송했다.

```powershell
wsl.exe -d Ubuntu-24.04 -e rsync -rt --exclude=.git/ --exclude=target/ --exclude=.artifacts/ -e /mnt/c/Windows/System32/OpenSSH/ssh.exe /mnt/d/Github/utils/way-toys/ debian@192.168.50.125:/home/debian/projects/way-toys/
```

VM의 `/home/debian/projects/way-toys`에서 `. "$HOME/.cargo/env"` 후 다음 명령을 실행했다. 기존 빌드 의존성을 사용했고 추가 패키지는 설치하지 않았다.

```bash
cargo fmt --all
cargo build -p waytoys-zones-editor --locked
cargo test --workspace --locked
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
```

[최종 검사 로그](artifacts/2026-10-31-17/validation.log)에 전체 74개 테스트와 fmt·Clippy 통과가 있다. 기존 69개에 미리보기의 겹침·포함 관계, 좌표/컨트롤, Grid 입력, 툴바, 잘못된 크기 검증 5개를 추가했다. VM의 rustfmt 결과도 Windows로 가져왔다.

이전 개발 Grid unit `waytoys-zones-editor-dev`를 종료하고 Canvas 미리보기를 띄웠다. 초기 `waytoys-canvas-preview-17`은 위 예제 조정 전 화면 확인용이고, 수정 후 `waytoys-canvas-preview-17-check`로 입력 검증했다. 최종 화면은 다음 명령으로 열어 뒀다.

```powershell
ssh debian@192.168.50.125 'systemd-run --user --unit=waytoys-canvas-preview-dev --collect --setenv=WAYLAND_DISPLAY=wayland-0 /home/debian/projects/way-toys/target/debug/waytoys-zones-editor --output Virtual-2 --preview /home/debian/projects/way-toys/crates/waytoys-zones-editor/examples/canvas-overlap.json --config-dir /home/debian/waytoys-test-results/canvas-preview-17/no-write'
```

## 실제 입력·캡처와 결과

16회차의 `scripts/vm-input.py`를 PVE `/tmp/waytoys-vm-input.py`에 SCP한 뒤 같은 호출 형식으로 QMP 입력을 보냈다. 아래 각 JSON을 순서대로 stdin에 전달했고 정규화 인수는 `--vm-id 700 --width 1962 --height 627`이었다.

- [input-readonly.json](artifacts/2026-10-31-17/input-readonly.json): 두 번째 화면의 사각형을 클릭하고 Ctrl+S를 보냈다. 서비스가 계속 active였고 검증용 `no-write` 경로가 생성되지 않았다.
- [input-switch.json](artifacts/2026-10-31-17/input-switch.json): `Next output`을 클릭해 첫 번째 모니터로 옮겼다. [첫 화면 캡처](artifacts/2026-10-31-17/canvas-overlap-virtual-1.png)에서 같은 네 구역의 축소된 논리 크기를 확인했다.
- [input-close.json](artifacts/2026-10-31-17/input-close.json): 첫 화면을 클릭해 포커스를 준 뒤 Esc로 정상 종료했다.

예제 JSON의 SHA-256은 `1667a205d9e0d0c8ca548ac3518a9d4678716754eb742c87b00b8dac2b3ce3c3`로 입력 시험 전후 같았다. [서비스·배율·읽기 전용 확인 로그](artifacts/2026-10-31-17/native-preview.log)를 보존했다. 첫 화면 버퍼는 848×480·1배, 두 번째는 논리 1113×626에 물리 1280×720·1.15배였다. 기존 Grid 설정 파일은 읽거나 쓰지 않았다.

캡처는 실제 `.\scripts\capture-vm.ps1 -NoOpen`으로 확인했고, 마지막에는 `-NoOpen` 없이 실행해 탭을 열었다. Spectacle의 VM 내부 PNG 원본을 가져오는 방식이며 Windows 클립보드를 사용하지 않았다. [최종 두 번째 화면 PNG](artifacts/2026-10-31-17/canvas-overlap-virtual-2.png)는 3922×1252, SHA-256 `aa72716a5651d29f7d94db4700d72bab3991816f1f3de76b1cf6629d93760417`이다. 브라우저에서 이미지 로드 완료와 원본 크기도 확인했다.

시험 unit은 Esc 또는 명시적 stop으로 정리했고 PVE의 임시 입력 스크립트도 제거했다. 최종 `waytoys-canvas-preview-dev`만 사용자가 볼 수 있도록 열어 뒀다. Close/Esc 또는 `systemctl --user stop waytoys-canvas-preview-dev`로 닫을 수 있으며 자동 시작은 등록하지 않았다.

## 한계

Canvas의 겹침을 실제 모델과 Wayland surface로 표시한 결과다. Canvas 이동·리사이즈·겹친 구역의 포인터 선택 UI나 실제 앱 창 배치는 구현·검증하지 않았다. 원본 FancyZones와의 픽셀 단위 동등성, 물리 모니터와 다른 컴포지터도 이번 범위 밖이다. 코드·패키지 검사 실패는 없었으며 예제의 라벨 가독성을 조정한 사항은 위에 기록했다. 커밋·푸시는 하지 않았다.
