# 2026-10-31-02 VM의 격리 X11 재현 환경 준비 실패

- 목적: 기본 Plasma 세션의 입력을 움직이지 않고 기존 X11 중첩 실험을 실행한다.
- 환경: VM 700 Debian 13, 기본 Plasma Wayland, KWin 6.3.6-1, Git `c02799b`. 앱 구현 변경 없음. 새 headless 래퍼는 미커밋 상태였다.
- 작업 디렉터리: `/home/debian/projects/way-toys`.
- 준비: `sudo apt-get install -y --no-install-recommends xvfb openbox wmctrl xdotool imagemagick xauth`.
- Windows에서 rsync 후 `git config core.autocrlf input`, `sed -i 's/\r$//' scripts/*.sh`, `chmod +x scripts/*.sh`를 실행했다. 새 SSH 세션에서 `. "$HOME/.cargo/env"`로 Cargo를 활성화했다.
- 실행: `sh scripts/reproduce-nested-overlay-headless.sh /home/debian/waytoys-test-results/2026-10-31-02`.
- 당시 래퍼는 Xvfb `3000x1600x24`, Openbox를 시작하고 기존 `reproduce-nested-overlay.sh equal`과 `mixed`를 순서대로 호출했다. 현재 래퍼에는 이후 호환성 처리가 추가됐으며, 최초 래퍼 원본은 별도 보존하지 못했다.
- 결과: `equal` 준비 중 `wmctrl -lpG`가 반복해서 segmentation fault를 내고 `Two nested windows not found`로 종료했다. `mixed`는 실행하지 못했다. 오버레이 검증 결과는 **미확인**이다.
- 원본 로그: VM의 `/home/debian/waytoys-test-results/2026-10-31-02/` 아래 `equal-run.log`, `equal/kwin.log`, `equal/scale.log`, `openbox.log`.
- 래퍼의 정리 경로에서 시험용 KWin, Openbox, Xvfb가 종료된다. 기본 Plasma 세션 설정은 변경하지 않았다.
