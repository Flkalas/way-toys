# 2026-10-31-11 캡처 자동 도구 최초 실행과 정리 지연

환경과 앱 버전은 [10](2026-10-31-10.md)과 같다. Windows `D:\Github\utils\way-toys`에서 `& .\scripts\capture-vm.ps1 -Overlay -Build`를 실행했다. 미커밋 PowerShell 도구가 GUI 캡처·Ctrl+C·PNG 전송·해시 검증·탭 열기까지 성공했다. Windows 클립보드는 조작하지 않았다.

결과는 `.artifacts/captures/20261031-034342-13e344/`에 있다. 3922×1252 PNG의 SHA-256은 `5fe182a80eb37f856f34fa653fc3f0dd684c7658b5baa10490445cf46460b0b3`다.

최초 정리 코드에는 `wl-copy --type image/png < "$out/clipboard.png"`가 있었다. 포크된 클립보드 제공 프로세스가 SSH 연결의 파일 디스크립터를 유지해 자동 종료가 지연됐다. 해당 시험 프로세스 PID 9129를 종료하자 명령이 끝났다. 따라서 이 회차의 정리는 수동 개입이 있었으며 완전 자동 성공으로 기록하지 않는다. 그 유지 코드를 삭제하고 [12](2026-10-31-12.md)에서 재시험했다. 최초 도구 전체 사본은 별도 보존하지 못했으며, 현재 도구에는 이 줄이 없다.
