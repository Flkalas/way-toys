# 2026-10-31-06 전체 화면 테두리 표시 첫 실행 실패

VM 700 Debian 13/Plasma Wayland/KWin 6.3.6, `c02799b` 위 미커밋 렌더러 변경을 시험했다. 각 출력 전체에 색과 테두리를 그리도록 수정한 첫 버전이다.

VM `/home/debian/projects/way-toys`에서 Rust 1.99.1로 `cargo build --workspace --locked`, `cargo test --workspace --locked`, `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`가 통과했다. 실제 표시에서는 재사용 SHM 슬롯이 현재 이미지보다 커서 테두리의 뺄셈이 overflow로 panic했다. 이 버전의 원본 사본은 별도 보존하지 못했다. 최종 버전은 실제 이미지 픽셀 수까지만 그리며, 큰 슬롯의 여분 영역을 보존하는 회귀 검사를 추가했다.

실행은 `sudo loginctl unlock-session 1` 후 `systemd-run --user --unit=waytoys-clipboard-capture --collect --wait --pipe /bin/sh /home/debian/projects/way-toys/scripts/capture-overlay-clipboard.sh /home/debian/waytoys-test-results/2026-10-31-06`였다. 당시 helper의 백그라운드 캡처 방식은 이후 수정·폐기됐다. VM의 해당 결과 디렉터리에 `overlay.log`, `outputs-before.json`이 남아 있다. 실패 후 시험 앱을 종료했다. 다음 회차는 [07](2026-10-31-07.md)이다.
