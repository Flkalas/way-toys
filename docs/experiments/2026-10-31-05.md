# 2026-10-31-05 VM 기본 Plasma Wayland 출력별 오버레이 캡처

## 환경과 목적

2026-10-31 03:26 KST, VM 700 Debian 13/KWin 6.3.6의 기본 Plasma Wayland 세션에서 출력별 오버레이가 나타난 모습을 캡처했다. 다른 KWin 인스턴스를 창 안에 띄우는 중첩 시험이 아니다. Git `c02799b`, 앱 구현 변경 없음. 앞선 회차의 미커밋 시험 스크립트가 존재하며 앱 바이너리는 이전에 검증한 Rust 1.99.1 디버그 빌드다.

- `Virtual-1`: 848×480, 배율 100%, 논리 시작 `(0,0)`.
- `Virtual-2`: 1280×720, 배율 115%, 논리 시작 `(848,0)`.
- `waytoys-overlay --display`: 두 출력 각각 독립 layer surface. 중앙 색 사각형은 의도적으로 각 출력의 가로·세로 60%다.

## 실제 실행 절차

Windows PowerShell, 작업 디렉터리 `D:\Github\utils`에서 기존 공개키 인증 SSH를 사용했다. VM의 자동 잠금을 먼저 해제하고 user systemd의 실제 로그인 세션 환경으로 앱을 실행했다.

```powershell
ssh debian@192.168.50.125 'sudo loginctl unlock-session 1; systemd-run --user --unit=waytoys-overlay-capture --collect /home/debian/projects/way-toys/target/debug/waytoys-overlay --display'
ssh debian@192.168.50.125 'journalctl --user -u waytoys-overlay-capture -n 10 --no-pager'
ssh INOPS-PVE 'printf "screendump /tmp/waytoys-vm700-monitors-overlay.ppm\nquit\n" | qm monitor 700'
$imageDir='D:\Github\utils\way-toys\docs\experiments\artifacts\2026-10-31-05'
New-Item -ItemType Directory -Path $imageDir -Force | Out-Null
scp INOPS-PVE:/tmp/waytoys-vm700-monitors-overlay.ppm "$imageDir\vm700-overlay.ppm"
python3.12 D:\Github\utils\way-toys\scripts\qemu-ppm-to-png.py "$imageDir\vm700-overlay.ppm" "$imageDir\vm700-overlay.png"
```

PNG 변환은 [보존한 표준 라이브러리 변환 스크립트](../../scripts/qemu-ppm-to-png.py)로 수행했으며, 화면 내용이나 색을 편집하지 않았다.

## 관찰 결과

- 앱 설정 로그는 첫 출력 `logical=848x480 scale=1 buffer=848x480`, 둘째 출력 `logical=1113x626 scale=2 buffer=2226x1252`였다. 둘째의 2는 정수 버퍼 배율이며 KWin 출력 배율 115%와 구분한다.
- QEMU 캡처는 2176×768이다. 왼쪽 화면에는 보라색, 오른쪽 화면에는 초록색 사각형이 나타났다. 두 오버레이가 첫째 출력에 몰리는 현상은 이 표시 시험에서 재현되지 않았다.
- [PNG 원본](artifacts/2026-10-31-05/vm700-overlay.png)을 Orca 내장 브라우저 탭으로 열고 2176×768 이미지가 로드됐음을 확인했다.
- 여러 출력을 합친 QEMU 프레임버퍼에는 검은 여백이 있다. 이를 게스트 논리 데스크톱 좌표와 동일하게 취급하지 않는다.
- 드래그 선택 좌표, 입력 통과, 물리 PC의 문제는 이 캡처만으로 검증하지 않았다.

## 整理

캡처 후 `ssh debian@192.168.50.125 'systemctl --user stop waytoys-overlay-capture'`로 시험 앱을 종료했다. 이미지 탭과 산출물은 남겼다.
